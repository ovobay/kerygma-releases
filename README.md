# Kerygma Downloads

Official Windows and macOS desktop installers for **Kerygma**, a church presentation application that detects Bible verses during sermons and prepares Scripture for live display.

## Downloads

Once the first release is published, visit the [latest release](https://github.com/ovobay/kerygma-releases/releases/latest) to get:

- **Windows x64:** `Kerygma-Windows-x64-Setup.exe`
- **macOS Apple Silicon (M-series):** `Kerygma-macos-arm64.dmg`
- **macOS Intel:** `Kerygma-macos-x64.dmg`

## Updates

Kerygma checks for new versions and offers signed in-app updates. It will not install an update without the operator's approval. Stop live output and transcription before updating.

The signed update manifest will be available as `latest.json` in the latest release once the distribution system is live.

## About this repository

This public repository is **only for release binaries and update manifests**. The Kerygma application's source code is kept in a separate, private repository.

> No public release has been published yet. Do not download installers from unrelated or unverified sources.
